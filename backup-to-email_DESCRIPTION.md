# Резервная копия MikroTik по почте

[backup-to-email.rsc](backup-to-email.rsc) для RouterOS 7.10 и новее отправляет одним письмом два вложения. Файл `.backup` содержит незашифрованную двоичную резервную копию, а `.rsc` — текст конфигурации, полученный стандартной командой `/export`.

## Настройка и запуск

1. В WinBox откройте **Tools → E-mail**. Укажите адрес SMTP-сервера, порт, адрес отправителя **From** и режим TLS, который требует провайдер. Если сервер требует авторизацию, введите имя пользователя и пароль. RouterOS хранит пароль SMTP в настройках **E-mail**.
2. В начале скрипта замените `recipient@example.com` в переменной `emailTo` на адрес получателя.
3. Запустите скрипт вручную или добавьте его в **System → Scheduler** для отправки по расписанию.

Имена обоих файлов содержат дату в формате `DD-MM-YYYY`. Если имя уже занято, скрипт добавляет суффикс к именам новой пары.

Если отправка завершилась ошибкой, скрипт повторяет её один раз через 30 секунд. После успешной отправки он удаляет только два файла текущего запуска. Если обе попытки завершились ошибкой или RouterOS не подтвердила результат за 30 секунд, оба файла остаются на роутере.
